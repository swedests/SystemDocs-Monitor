# 🧰 Шпаргалка для настройки тревог HWiNFO

> Таблица составлена по ручным настройкам владельца в HWiNFO64 8.52 для компьютера из [README проекта](../README.md). Исходные изображения настроек в проект не включены; не копируй эти значения на другой ПК без проверки.

## 📣 Что увидит пользователь

Если появилось окно тревоги:

1. Закрой игру или программу, которую только что запускал.
2. Сфотографируй окно и отправь фото владельцу ПК по контакту из сообщения Windows при входе.
3. Не открывай корпус и не меняй настройки компьютера.

В каждой памятке есть возможные причины (это не диагноз), технический блок с названием датчика, порогом и проверками в HWiNFO/Windows, а также совет для тех, кто не знает, что делать: штатно выключить компьютер и сообщить владельцу. С электричеством шутки плохи — не пытайся ремонтировать ПК сам. Корпус открывает только владелец; снаружи можно проверять лишь кабели монитора и периферии.

`alert.ahk` получает только текстовый аргумент, например `cpu`, и по нему открывает файл памятки. Программа не считывает сами значения датчиков из HWiNFO.

## 🔎 Что сейчас не подключено к памяткам

В исходной проверке настроек для датчиков **«Система 1»**, вентиляторов видеокарты, использования памяти видеокарты, доступного резерва SSD и ошибок диска не было настроено запуска памятки.

У `CPU VCORE SoC`, `DRAM`, `3VSB` и `AVCC3` в HWiNFO отображается статус «Да». Он подтверждает наличие уведомления, но сам по себе не показывает, запускает ли оно программу и с каким аргументом. В проекте эти настройки не сохранены, поэтому связь с `alert.ahk` подтвердить нельзя. Если для них включён **Run a program**, укажи аргумент, существующий в карте скрипта.

## ⚙️ Как связаны настройки и код

Для каждого нужного датчика в HWiNFO вручную включается тревога, задаётся порог и действие **Run a program** с путём к `scripts\alert.ahk`. В аргументе указывается тип из таблицы выше. HWiNFO должен быть запущен, иначе проверка порогов не выполняется.

Файл `.ahk` запускается установленным AutoHotkey UX через ассоциацию Windows. Директива `#Requires AutoHotkey v1.1.33+` направляет скрипт в совместимую версию v1.1, даже если на компьютере установлена v2.

HWiNFO здесь настроен вручную: приложение проекта не создаёт эти пороги. При изменении датчика или порога обнови и эту таблицу.
